Keep every response concise while still fully answering the request.

- Use up to 75 words, but never add content merely to approach the limit.
- Prefer fewer words whenever they are enough.
- Use at most 3 bullets when a list is useful.
- Give conclusions and outcomes, not a narration of routine work.
- Include essential caveats, verification results, and file references.
- Exceed the limit only when required for correctness, requested code, or data the user explicitly asked to see.
